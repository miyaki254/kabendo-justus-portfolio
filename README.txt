RUN LOCALLY
- Extract the ZIP file.
- Open the folder.
- Double-click index.html to open the home page in a browser.

HOST ON GITHUB PAGES
1. Sign in to GitHub and create a new public repository named yourname-portfolio.
2. Upload all five HTML files, style.css, script.js, README.txt and the images folder.
3. Open the repository Settings.
4. Select Pages from the left menu.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder / (root), then Save.
7. Wait for GitHub Pages to publish. Your link will look like:
   https://YOUR-USERNAME.github.io/yourname-portfolio/
